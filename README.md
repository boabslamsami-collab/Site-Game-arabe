# ألعابنا 🎮

عشر ألعاب عربية مجانية تعمل مباشرة في المتصفح باستخدام HTML وCSS وJavaScript، بدون تسجيل أو تنزيل. الصفحة الرئيسية للموقع هي `index.html`.

## تفعيل GitHub Pages (مرة واحدة)

1. افتح **Settings** في المستودع ثم اختر **Pages**.
2. تحت **Build and deployment** اختر **GitHub Actions** كمصدر النشر.
3. بعد اكتمال سير العمل في تبويب **Actions** افتح: https://boabslamsami-collab.github.io/Site-Game-arabe/

بعدها سيُنشر الموقع تلقائياً مع كل تحديث إلى فرع `main`. ملفات تطبيق Flask/Python السابقة باقية في المستودع، لكن GitHub Pages يشغّل النسخة الثابتة الجديدة من المتصفح.
