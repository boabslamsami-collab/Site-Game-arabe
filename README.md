موقع ألعاب مصغّر باللغة العربية يضم 10 ألعاب تفاعلية، مطوّرة باستخدام Python وFlask، مع واجهة متوافقة مع الهاتف والكمبيوتر.

1. الرقم السري 🔢
2. حجر ورقة مقص ✊
3. إكس أو ⭕
4. اختبار المعلومات 🧠
5. خمن الكلمة 🔤
6. تحدي الحساب ➕
7. أكمل النمط 🧩
8. صح أم خطأ ✅
9. الكلمة المبعثرة 🔀
10. 21 المصغرة 🃏

## التشغيل محلياً

يتطلب Python 3.10 أو أحدث.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ثم افتح http://127.0.0.1:5000 في المتصفح.

## النشر

المستودع جاهز للنشر على خدمات تستضيف تطبيقات Python مثل Render. أنشئ Web Service من هذا المستودع، واجعل أمر البناء `pip install -r requirements.txt` وأمر التشغيل `gunicorn app:app`. أضف متغير بيئة `SECRET_KEY` بقيمة عشوائية قوية.

> GitHub Pages لا يشغّل تطبيقات Python/Flask؛ يمكن استخدامه لصفحات HTML ثابتة فقط. هذا المشروع يعمل كتطبيق Flask على خدمة استضافة تدعم Python.
